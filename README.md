# Аудиополка

Личная читалка аудиокниг: полка, главы, скорость, таймер сна с плавным затуханием, светлая и тёмная темы.
Книги хранятся только в браузере на устройстве (IndexedDB) и никуда не загружаются.

## Установка на телефон

- **iPhone:** открыть сайт в Safari → «Поделиться» → «На экран „Домой"».
- **Android:** открыть сайт в Chrome → меню ⋮ → «Установить приложение».

## Обновление

1. Положить новую версию страницы в `src/audiopolka.html`.
2. Запустить `python3 build.py`: соберётся `index.html` и обновится версия кэша в `sw.js`.
3. Закоммитить и запушить: GitHub Pages обновится сам.
